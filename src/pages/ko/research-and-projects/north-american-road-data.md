## 개요

북미 지형과 차량 섀시 연구에 쓸 도로 이미지 데이터셋을 만드는, 현재 진행 중인 프로젝트입니다. 현대자동차 제네시스샤시시험팀, ㈜베가스, 고려대학교 Big Data Mining Lab이 함께하고 있습니다.

저는 데이터 파이프라인을 설계하고 비전 연구를 맡고 있습니다. 어려운 건 이미지를 내려받는 일이 아닙니다. 모든 이미지가 요구하는 지역, 촬영 시기, 해상도 조건을 만족해야 하고, 거의 똑같은 사진이 넘쳐나지 않아야 하며, 사람이 하는 검수 작업이 실제로 감당할 수 있는 양이어야 합니다.

## 파이프라인

<ol class="flow">
  <li><strong>조건부 수집</strong>지역, 촬영 시기, 최소 해상도를 기준으로 Mapillary API 요청을 구성합니다.</li>
  <li><strong>임베딩</strong>DINOv3가 도로 이미지를 특징 벡터로 바꿉니다. 이미지 내용을 숫자로 압축해 표현한 것입니다.</li>
  <li><strong>유사 이미지 검색</strong>FAISS로 벡터를 빠르게 검색해 비슷한 장면을 묶고 거의 중복된 이미지를 걸러 냅니다.</li>
  <li><strong>사람의 검수</strong>간단한 라벨링·검수 도구에서 사람이 이미지를 한 장씩 확인한 뒤에야 데이터셋에 들어갑니다.</li>
</ol>

## 중점을 두는 부분

데이터 품질을 마지막에 치우는 일이 아니라 설계 문제로 봅니다. API 제한, 중복·유사 중복 이미지, 일관되지 않은 메타데이터, 검수에 드는 사람의 시간을 처음부터 고려합니다. 이렇게 하면 불필요한 처리를 줄일 수 있고, 나중에 어떤 결정이 왜 내려졌는지 추적하기도 쉬워집니다.

## 현재 상태

2026년 7월부터 파이프라인과 검수 흐름을 개발하고 있습니다. 이 페이지에서는 접근 방식만 소개하며, 협력사의 데이터와 기밀 구현 내용은 공개하지 않습니다.
